# gate-integrity-register.txt — every place in this repository where a check declines to run,
# discards a failure, reports an obligation away, or has no invocation at all.
#
# READ BY scripts/check-gate-integrity.py. Format, one entry per line:
#
#     kind :: key :: count :: reason
#
#   skip     a test or check that declines to run.  count = sites at that key
#   swallow  a gate invocation whose failure is discarded (`|| true`, `|| echo`)
#   inert    a graded obligation reported notApplicable rather than graded
#   unwired  a real gate with no call site — DEBT. count is 0; the LIST may only shrink
#   exempt   a file the gate's naming convention read as a gate and which is not one
#
# The key is the file's LAST TWO PATH SEGMENTS plus the enclosing function, target or
# section. Two segments rather than a full path so this register is portable between
# checkouts that hold different subsets of the tree. A key that would name two files is
# exit 2, never a silent merge of their counts.
#
# THIS IS NOT THE ONLY REGISTER. Any file named gate-integrity-register.txt in a directory
# the gate walks is loaded too, and its entries count exactly as this file's do. A subtree
# that is not in every checkout keeps its entries in a register beside it, so a checkout
# without the subtree has neither its files nor entries that would report them REPAIRED.
# This file lists only what every checkout carries. An entry named in two registers is
# exit 2, the same refusal as a key that names two files.
#
# THIS IS A RATCHET, NOT AN AMNESTY. It fails in four directions, on the same terms the
# documentation-voice register already uses:
#
#     NEW       a site not listed here
#     WORSE     more sites at a key than are listed
#     SHRUNK    fewer — lower the number. An accurate register is the whole product
#     REPAIRED  a listed site that no longer exists, or an `unwired` gate that is now wired
#
# WHY A COUNT AND NOT A LINE NUMBER. A skip is not a line: an edit above one moves it, and a
# line-keyed register would go red on unrelated edits and be switched off inside a week.
#
# WHY EVERY ENTRY CARRIES A REASON. A skip is legitimate — the optional control-plane
# binaries are real, and adapters released from other repositories are really absent. The
# requirement is not zero skips. It is that every skip is NAMED, EXPECTED and COUNTED, so a
# new one cannot hide inside a green run. An entry with no reason is refused at load.
