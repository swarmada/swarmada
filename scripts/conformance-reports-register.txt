# conformance-reports-register.txt — the gate-integrity entries for the conformance reports.
#
# `make conformance-profiles` writes the reports into conformance-reports/ and installs this file
# beside them as conformance-reports/gate-integrity-register.txt, which
# scripts/check-gate-integrity.py loads as an overlay with scripts/gate-integrity-register.txt.
# Format, kinds, keys and the four-way ratchet are that file's; read its header. An entry named
# here AND there is exit 2. Edit THIS file; the copy is overwritten on every run.
#
# ONLY LEVELS conformance/profiles.yaml DECLARES. An entry for a level that exists only because a
# registry overlay (rfcs/*/conformance-registry.yaml, which a tree may not carry) declares it
# goes beside that overlay, in conformance-reports-register.txt, and is installed with this file
# only where the overlay is (the Makefile's CONFORMANCE_REGISTER_SOURCES). Listed here, it reports
# REPAIRED on every tree without the overlay.
#
# WHY IT IS COPIED, NOT LOADED FROM HERE. The reports are generated artefacts and
# conformance-reports/ is not published, so a clone has no reports until it runs the target. In
# the published register every entry below reported REPAIRED on such a clone; kept only beside
# the reports, where the target never wrote them, every entry reported NEW once it had run. The
# target writes both, so the counts travel with the reports they describe: absent together,
# present together.
# ── inert · a graded obligation reported notApplicable ───────────────────────────────────
# notApplicable leaves the pass/fail counts entirely: the level neither passed nor failed the
# check, and a reader scanning statistics sees no debt. Each one is listed so that a profile
# reporting away exactly the obligation it owes is a visible change and not a quiet one.
