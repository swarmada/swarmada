# Code of Conduct

The Swarmada project adopts the
[CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md),
which is based on the [Contributor Covenant](https://www.contributor-covenant.org/).

All contributors, maintainers, and participants — in this repository, in issues and
pull requests, in community channels, and at any project event — are expected to
uphold it.

## Reporting

To report a Code of Conduct concern, contact the maintainers privately at
**`<conduct@swarmada.io>`**. Reports are handled confidentially. Once Swarmada is a
CNCF project, concerns may also be reported to the CNCF Code of Conduct Committee as
described in the linked policy.
